OOAD Practical Assignment

You are tasked with designing a Smart Home Automation System.
This system will control various smart devices (like lights, thermostats, and alarms)
and respond to user-defined conditions or external events
(e.g., time of day, temperature, or motion detection).
The design should be extendable and follow key object-oriented design principles.

Patterns to apply:

Observer Pattern
    to design a central event dispatcher which responds to changes in a central state
    such as time, temperature and motion events.

Strategy Pattern
    to design different behavioral strategies for home automation
    (e.g., Energy Saving Mode, Security Mode, Vacation Mode).

Abstract Factory Pattern
    to create a family of related devices, each with its own implementation of light
    and alarm etc.

Singleton Pattern
    to design the central controller managing the system’s state and events to
    ensure consistent behavior throughout the system.

Tasks : -
    Design the class diagram for this system, clearly identifying:
    The key participants of each design pattern used.
    The interactions between components.
    Implement the core components of the system in code (you may choose Java or C++).
    Focus on a minimal but functional implementation of each design pattern.

What to submit:-

    Design document (class structure of the system)
    Source code (Zip file containing all programs)
